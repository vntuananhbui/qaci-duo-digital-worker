# QACI Duo playbook library (published)

This branch is generated from `main` by the `Publish library` workflow. Do not edit it; open a pull request against `main`.

## Digital Worker

Install a whole Digital Worker in QACI Duo: **+ → Templates → Community templates → Load → Add team**.

- **ADLC** — One agent for the full delivery lifecycle: requirements, planning, implementation, verification and deployment, with your approval before anything ships.
- **Experiment Designer** — Give it a survey and an idea, get a reviewed experiment plan with numbers to reproduce, fixed pass and fail criteria, and a budget that fits.
- **Literature Surveyor** — Know where the field stands and whether your idea is new, from papers that were verified against registries and read in full.
- **Social Media Marketer** — A month of sourced, on-brand posts, a daily post from fresh news, and a weekly report from real numbers, with nothing going public until you approve it.
